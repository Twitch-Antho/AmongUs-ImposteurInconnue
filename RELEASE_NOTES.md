## Imposteur Inconnu — compatible Among Us 2026.9.29

Mise à jour complète du mod pour la version actuelle d'Among Us, avec **BepInEx 6 IL2CPP (be.735)** et **Reactor 2.5.1**.

### Téléchargement

| Fichier | Pour qui |
|---|---|
| `ImposteurInconnu-Steam-Itch.zip` | Steam ou Itch.io (BepInEx + Reactor + mod, prêt à l'emploi) |
| `ImposteurInconnu-Epic-MicrosoftStore.zip` | Epic Games ou Microsoft Store |
| `AmongUsUnknownImpostors.dll` | Seulement la DLL, si BepInEx et Reactor sont déjà installés |

### Installation

1. Extraire le .zip dans le dossier du jeu (ex : `steamapps/common/Among Us`).
2. Lancer le jeu. Le premier lancement prend un peu plus de temps.

### Nouveautés

- Les imposteurs ne se connaissent pas : intro, noms, réunions et chat.
- Les imposteurs peuvent s'entre-tuer.
- Vision des imposteurs réglable quand les lumières sont sabotées.
- Réglages par l'hôte depuis le chat du lobby : `/inconnu on`, `/inconnu off`, `/inconnu vision 1.5`.
- Le mode reste désactivé si l'hôte n'a pas le mod.
